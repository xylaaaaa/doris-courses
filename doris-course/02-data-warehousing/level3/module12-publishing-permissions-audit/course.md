# 模块 12：发布、权限与审计

## 模块目标

学习数据仓库受控的运维边界：发布数据产品时先检查范围、证据和恢复方案，再修改访问权限或存储。

## 学习目标

1. 为已发布数据产品定义负责人和消费者契约
2. 使用角色和授权，只授予消费者所需的表权限
3. 区分数据库权限和管理权限
4. 检查授权并记录发布审计轨迹
5. 在不改变数据产品的情况下撤销访问权限

## 动手实验

[`lab12_publishing_permissions_audit.ipynb`](lab12_publishing_permissions_audit.ipynb) 使用专用的 `dw_course_l1_*` 数据库。执行任何写入或权限语句前，请检查清理范围。

## 模块总结

- 在修改数据或权限前检查元数据和所有权。
- SQL 执行成功只是一个观察结果，不足以证明完整的运维正确性。
- 在维护交接中记录范围、证据和恢复步骤。
